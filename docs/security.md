# 安全边界与验证

本轮审查日期：2026-11-15。覆盖客户分享页、订阅、用户分流接口、管理接口、Agent 配置边界和代理对内部服务的访问；不代表经过独立渗透测试或不存在未知漏洞。

Linux + 真实 sing-box 1.14.3 回归覆盖代理核心及面板功能；用户密码版本另覆盖首次设密并发、认证撤销、限速、CSRF、跨用户隔离和表单解析兼容性。独立生产冒烟检查覆盖五协议的外部 HTTPS 连通性、五类订阅/UA、客户响应脱敏及既存用户权限不变；不对生产统计执行重置或攻击测试。

## 用户能看到什么

用户只能查看自己的节点、连接凭据、用量、授权出口的公开资料和自己的分流规则。上游连接地址、端口、密码、UUID、私钥及内部名称不进入客户 API、HTML 或订阅；没有公开名称时使用稳定的匿名出口标签。公开名称和说明由管理员填写，不应含私密信息。

用户面板、流量详情、二维码、个人分流 API 和节点密码修改均要求独立的用户登录会话。未设密账号由首次持有专属链接的人设置 10–128 字符密码；首次链接因此仍须私下交付。密码仅以 Argon2 哈希保存。管理员随机重置只在成功响应中显示一次明文，账号改密、退出或管理员重置会递增认证版本，撤销旧会话；链接轮换和删除重建也会使旧会话失效。修改节点密码和分流请求在取得运行锁后重新检查认证与授权，撤权操作使用同一把运行锁。

客户端自动订阅仍是持有令牌即授权：显式格式或已识别客户端 UA 可以下载该用户的节点凭据和用量响应头，不创建面板会话。面板密码不能弥补订阅链接泄漏；泄漏时应轮换链接，必要时同时轮换节点凭据。UA 或 `format` 参数不会豁免二维码、个人分流或其他交互接口的登录要求。

认证入口限制请求大小、字段数、单账号/IP/全局频率和并行 Argon2 运算；首次设密、登录后的版本复查及改密使用事务，避免并发覆盖管理员重置。所有认证写操作均校验 CSRF。HTTPS 部署必须设置 `PANEL_SECURE_COOKIE=1`。

代理出口的实际公网 IP 无法对使用者保密：用户可以通过 IP 查询网站观察出口。这与面板不下发上游连接参数是不同的边界。

## 强制网络隔离

本机和 Agent 的配置均在所有管理员及用户分流规则之前加入系统保护，禁止代理目标访问环回、RFC1918、链路本地、云元数据、ULA 等内部地址，并拒绝面板、统计和控制接口的目标端口。该保护没有生产环境关闭开关。

域名先在节点机器解析，再检查解析结果；后续业务规则复用已检查的地址，避免重复解析绕过检查。服务端 DNS 必须能解析公网目标，仅能在上游内部解析的域名不再适用。规则集下载及管理员配置的上游服务器拨号不受这组入站目标规则限制。远端独立上游自己的 NAT 或转发规则不在面板控制范围内。

修复前，仅将无认证的统计 API 绑定到 loopback 不足以保护它：已认证代理用户可以经节点回连该接口读取或重置他人计数。回归测试使用隔离核心和临时数据库，验证用户 A 的读取及重置请求被拒绝、用户 B 的计数不减少，同时覆盖正常公网目标、TCP/UDP 和私网上游服务器拨号。

客户“匹配预览”也会对明确的内部 IP 返回系统拦截。域名预览不发起 DNS 查询或连接，因此不能代替真实网络测试。

## 注入与授权检查

回归覆盖跨用户节点和出口授权、管理员接口隔离、CSRF、分享令牌撤销、公开响应字段白名单，以及脚本闭合、HTML 和模板表达式载荷。模板保持自动转义，JSON 使用安全编码，动态文本使用文本节点；客户提交的匹配条件和出口标识经过白名单验证，不作为 shell 或模板代码执行。

所有协议的业务计量回归中，少数夹具需要连接本机测试 HTTP/UDP 服务；它们显式使用仅位于 `tests/` 的临时适配器。网络隔离测试不使用该适配器，生产代码没有对应开关。

## 部署要求

管理网页、分享页和 Agent WSS 都应使用端到端 TLS。Cloudflare 的 Flexible 模式只加密客户端到边缘，边缘到源站仍是 HTTP；准备源站证书不会自动改变 Cloudflare 回源模式。切换需对相应主机设置 Full (strict)，并确认其他站点不受影响。

数据库、认证文件、TLS 私钥、备份和 Agent 凭据不得进入 Git。生产数据只在服务器保存，代码发布不得覆盖生产数据库。修改前保留在线数据库快照和代码备份；依赖升级在独立环境运行完整测试后再上线。
