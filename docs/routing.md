# 服务器分流管理

管理端导航“分流管理”，路径为管理前缀下的 /routing。此功能控制服务器出口，客户端仍连接原来的节点；不会把管理员上游凭据写入用户订阅。

## 使用

1. 添加上游出口，手动填写或解析一条分享链接；确认协议参数后保存。
2. 点“测试”检查经该出口访问 HTTPS 探测地址的延迟。
3. 添加规则，选择域名、域名后缀、关键词、IP/CIDR、目标端口/范围、TCP/UDP、嗅探协议及来源节点，指定直连、拦截或上游出口。
4. 规则从上往下匹配，可编辑、排序、停用。未命中规则使用默认出口。初始默认服务器直连，不内置外部出口或业务规则。

嗅探协议条件需要先启用协议嗅探。来源节点映射包含共享入站和独立用户入站；节点删除或没有有效入站时，该来源限定规则跳过，不会退化为全局规则。全量规则需明确勾选“匹配全部”。跨维度条件遵循 sing-box 规则匹配语义。

## 上游协议

SOCKS5（含认证）、HTTP/HTTPS、Shadowsocks/SS2022、VMess、VLESS（TLS/Reality）、Trojan、AnyTLS、Hysteria2、TUIC、Snell v4/v6。Snell v4 出站用于兼容 v5 服务端，支持共享模式 Userkey、HTTP 混淆。VLESS/VMess/Trojan 支持 TCP、WebSocket、gRPC、HTTPUpgrade。界面按协议和 TLS/传输选择显示相应选项。

可解析常见 socks/socks5/http/https/ss/vmess/vless/trojan/anytls/hy2/hysteria2/tuic/snell 分享 URI。SS SIP003 插件链接明确拒绝。TLS 默认校验证书，手动勾选或链接明确指定时才跳过。HTTP 上游不提供通用 UDP 转发；其他协议的 UDP 能力取决于上游服务器和协议。

## 保存与恢复

设置以 server_routing 键保存到 SQLite settings，包含出口、规则顺序、默认出口和嗅探开关。凭据只在管理员编辑 / 导入时使用；列表和配置预览不返回密码、UUID 等认证字段。编辑密码留空保留旧值，SOCKS5/HTTP 可明确清除认证。

保存先独立校验出口，再校验完整配置；持有核心运行锁写入设置并应用，启动失败恢复旧设置和旧核心配置。原有流量采样、用户额度、周期重置和节点计量保持在入站侧，不重复统计上游。保存生效可能导致连接重连。

已被规则或默认策略引用的出口不能删除或停用，需先修改引用。退出上游失败不会自动改走直连，避免绕过用户指定的出口策略。

“测试”通过仅本机可访问且有密钥的 Clash API 发起出口 URL 测试，目标 https://www.gstatic.com/generate_204，超时 3 秒，不会将凭据交给该探测网站。测试失败不会修改路由策略。

## 验证与部署

真实核心测试覆盖带认证 SOCKS5、SS AEAD、SS2022 上游的路由命中、默认直连、指定默认出口和拦截；包括控制 API 的出口延迟测试。另覆盖 URI 导入、所有协议配置 check、顺序调整、引用保护、CSRF/登录保护、凭据不泄露、保存失败回滚和来源节点消失的处理。

上线前备份 /opt/sing-panel/backups/before-routing-20261103.tar.gz 与 before-routing-20261103.db。上线不预设真实上游或业务规则。

## GeoIP / Geosite

规则编辑页提供 SagerNet 官方规则集目录，可搜索并多选国家、地区或域名分类。当前目录快照包含 238 个 GeoIP、1,995 个 Geosite 项。每一分类内为 OR，不同分类与其他条件之间为 AND；内网使用独立的“仅内网 IP”条件。

使用现代 sing-box binary `rule_set`，不依赖已移除的 geoip/geosite 核心字段。首次保存会从官方 GitHub 下载并通过实际核心校验 SRS，再应用设置；下载失败保留旧配置。初始文件保存在数据目录 `rule-sets/`，核心缓存位于 `routing-cache.db`，通过直连每 24 小时自动更新。已有缓存可用于后续离线启动。管理端的规则目录为随项目发布的快照，规则内容由核心自动更新。

## 用户自定义分流

分享页顶部新增“我的分流”。原分享地址继续按客户端 UA 分发订阅；用户分流在服务器执行，上游连接凭据不下发客户端。

管理员配置步骤：

1. 编辑出口，开启“用户可见”，填写公开名称、地区、说明，选择全部用户或指定用户／分组。是否允许使用可独立设置。
2. 在用户列表点击“分流设置”，开启权限并设置规则数量上限，默认最多 6 条。默认不开放，旧用户和旧出口的权限保持不变。
3. 将允许用户覆盖的管理员规则改为“默认规则”。已有规则仍为“强制规则”，节点固定出口保持原行为。
4. 用户通过自己的分享链接进入“我的分流”，直接选择网站服务（GeoSite）、目标 IP 地区（GeoIP）、域名后缀或 IP/CIDR，再选择授权出口。也可选择拦截。

用户规则从上到下匹配；同一条规则的多个值表示任一命中。规则支持复制、启停、拖动及上移／下移、指定自己的节点。未匹配流量跟随管理员。优先顺序为强制规则 → 个人规则 → 管理员默认规则 → 系统最终出口。

编辑只保存草稿，不影响连接。点击“应用更改”后进入统一发布队列，附近时间提交的变更合并处理；页面自动更新等待、应用中、成功或失败状态。校验／下载失败保持已应用策略；核心启动失败恢复原策略。发布具有恢复日志，异常退出后优先恢复上一个版本。当前发布仍可能重启整个核心，所有用户的连接可能短暂重连，并非无损热更新。

用户的共享入站按认证身份匹配，Snell 独立端口按用户专属入站匹配；无有效节点的用户规则不会退化成全局规则。管理员撤回出口使用权限时，原规则标记不可用，其匹配流量被拦截，不自动切换直连。账号停用、到期或额度耗尽后只能查看，不能应用；上游流量仍在原用户入站计费，不重复累计。

“匹配预览”使用已保存草稿和本机 SRS 快照，不主动访问输入的目标。尚未加载的规则集需先应用；缺少域名、目标 IP、端口或协议事实时显示“待确定”。这是配置推演，不是连通性证明。“出口测试”仅检测服务器经过授权出口访问固定探测目标的延迟，缓存标注检测时间。

客户端已按模板直连的流量不会进入服务器，不受这些规则控制。开启权限后，持有用户分享链接即可管理该用户的分流，不再要求额外密码。管理员关闭权限后停止写入，更换分享令牌后旧链接立即失效。接口限制规则数量、条件数量、发布频率与预览并发，并校验 CSRF、用户身份、节点及出口授权。
