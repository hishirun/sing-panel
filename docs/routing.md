# 服务器分流管理

管理端导航“分流管理”，路径为管理前缀下的 /routing。此功能控制服务器出口，客户端仍连接原来的节点；不会把管理员上游凭据写入用户订阅。

## 使用

1. 添加上游出口，手动填写或解析一条分享链接；确认协议参数后保存。
2. 点“测试”检查经该出口访问 HTTPS 探测地址的延迟。
3. 添加规则，选择域名、域名后缀、关键词、IP/CIDR、目标端口/范围、TCP/UDP、嗅探协议及来源节点，指定直连、拦截或上游出口。
4. 规则从上往下匹配，可编辑、排序、停用。未命中规则使用默认出口。初始默认服务器直连，不内置外部出口或业务规则。

嗅探协议条件需要先启用协议嗅探。来源节点映射包含共享入站和独立用户入站；节点删除或没有有效入站时，该来源限定规则跳过，不会退化为全局规则。全量规则需明确勾选“匹配全部”。跨维度条件遵循 sing-box 规则匹配语义。

## 上游协议

SOCKS5（含认证）、HTTP/HTTPS、Shadowsocks/SS2022、VMess、VLESS（TLS/Reality）、Trojan、AnyTLS、Hysteria2、TUIC、Snell v4/v6。Snell v4 出站用于兼容 v5 服务端，支持共享模式 Userkey、HTTP 混淆。VLESS/VMess/Trojan 支持 TCP、WebSocket、gRPC、HTTPUpgrade。界面按协议和 TLS/传输选择显示相应选项。

可解析常见 socks/socks5/http/https/ss/vmess/vless/trojan/anytls/hy2/hysteria2/tuic/snell 分享 URI。SS SIP003 插件链接明确拒绝。TLS 默认校验证书，手动勾选或链接明确指定时才跳过。HTTP 上游不提供通用 UDP 转发；其他协议的 UDP 能力取决于上游服务器和协议。

## 保存与恢复

设置以 server_routing 键保存到 SQLite settings，包含出口、规则顺序、默认出口和嗅探开关。凭据只在管理员编辑 / 导入时使用；列表和配置预览不返回密码、UUID 等认证字段。编辑密码留空保留旧值，SOCKS5/HTTP 可明确清除认证。

保存先独立校验出口，再校验完整配置；持有核心运行锁写入设置并应用，启动失败恢复旧设置和旧核心配置。原有流量采样、用户额度、周期重置和节点计量保持在入站侧，不重复统计上游。保存生效可能导致连接重连。

已被规则或默认策略引用的出口不能删除或停用，需先修改引用。退出上游失败不会自动改走直连，避免绕过用户指定的出口策略。

“测试”通过仅本机可访问且有密钥的 Clash API 发起出口 URL 测试，目标 https://www.gstatic.com/generate_204，超时 3 秒，不会将凭据交给该探测网站。测试失败不会修改路由策略。

## 验证与部署

真实核心测试覆盖带认证 SOCKS5、SS AEAD、SS2022 上游的路由命中、默认直连、指定默认出口和拦截；包括控制 API 的出口延迟测试。另覆盖 URI 导入、所有协议配置 check、顺序调整、引用保护、CSRF/登录保护、凭据不泄露、保存失败回滚和来源节点消失的处理。
